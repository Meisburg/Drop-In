(`DropInCard.tsx`). Verification, run against the built bundle on port 4191 with
chrome-devtools-axi (`page.eval`, DOM read of the Northgate card's going line):

    <span aria-hidden="true" class="... bg-slate-200 ...">E</span>

     "img":[{"alt":""}],

avatar (`img alt=""`) stays decorative because the adjacent `@Jon Meisburg`
label already names it. Visible name text is still not added anywhere on a card.
